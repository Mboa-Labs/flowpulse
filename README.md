# FlowPulse

**Optimisation intelligente des transports urbains et prédiction du trafic par données mobiles — Yaoundé**

Projet de l'équipe **Mboa Labs** pour le *AI for Good Lab Hackathon : United Arab Emirates* (ITU).

FlowPulse exploite les flux de mobilité issus des antennes mobiles pour anticiper la congestion et recommander des réaffectations de bus. Ses agents IA vérifient chaque recommandation au regard des textes réglementaires camerounais, citent leurs sources et signalent les manques réglementaires.
